# Security policy

## Reporting a vulnerability

Report a vulnerability privately through GitHub's private vulnerability reporting: open the
[Security tab](https://github.com/delairec/planet-crafter-save-tools/security) of the repository and choose
**Report a vulnerability**, or go straight to
[the reporting form](https://github.com/delairec/planet-crafter-save-tools/security/advisories/new).

Do not open a public issue or pull request for a vulnerability. The report stays visible to the maintainer alone
until a fix is published.

## Scope

- The web UI served at https://planet-crafter-save-manager.netlify.app/.
- The command-line tools and packages of this repository, on the default branch.
