*Feedback for the awawa dev team · awawa 2.7.0 · 2026-09-25*

# Migration 4: agent instructions, walked with starter v2

The second walk of the starter, and the first of its version 2: Flow S built an awawa corpus from scratch for the
global instructions a user gives to AI agents — 23 instruction files, 478 statements, replaced by 237 entities. The
object had no code to anchor, and was itself a set of documents. The walk found 26 defects, 7 in awawa 2.7.0 and 19
in the starter; this page lists them in the order they were met, and answers the 19 with a version 3 of the starter.

- **23** — instruction files replaced, 478 statements
- **237** — entities written
- **26** — defects: 7 in awawa, 19 in the starter
- **8** — steps walked, S1 to S8, 2026-09-24 to 2026-09-25

## The starter, version 3

Version 3 answers the 19 defects above, row by row; its « What Changed Since Version 2 » section lists the changes, and
a table maps the step identifiers of version 2, which the earlier reports cite, to the new ones. Nine of the ten
behaviours of awawa it adds to its table were re-probed on 2.7.0 on 2026-09-25; the tenth, that no command prints the
field values of a type, is taken from the walk. Flow M and the compact walk it proposes have not been
walked yet.
